主业务流程 e2e

覆盖用户真实链路：根 index.html 引导挂载主应用 → 欢迎首屏渲染 → 官方应用安装（todo/client、conjure）→ 安装副本完整性 → 经 /$mazmot-apps 命名空间实际运行两个应用。 conjure 的运行用例即用户反馈「加载页面模块 …/conjure/client/pages/home.html 失败」的回归网。

前置：需先安装 NoneOS Core——完整套件由 _setup/install-nos.sb.html 先行完成； 单文件跑请执行 npm run handshake 后 npx sb-test -f _setup/install-nos.sb.html -f main/test/boot-flow.sb.html --browsers chrome。 本文件会写入真实数据（mazmot 空间 apps 记录 + mazmot-apps 命名空间应用副本）， 用例幂等可重跑；套件中由清单追加保持在最后执行，不污染其他用例。
