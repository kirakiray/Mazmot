# Mazmot 桌面运行时 Context（client/）

Tauri 2 桌面壳：把 Mazmot 静态站点封装为原生多窗口的应用运行时。本文件是本目录的**活文档**，记录当前架构与活跃流程；开发规范见 [`AGENTS.md`](AGENTS.md)，面向人的使用说明见 [`README.md`](README.md)。

## 架构总览

```
┌─ WebView（每个窗口一个，origin = http://localhost:30031|30032）
│    站点静态文件（index.html 引导 → NoneOS Core SW 接管 /nos/* /gh/* /$xxx/*）
│    shim.js（initialization_script 注入）：window.open → runtime_* 命令
│                              ▲ eval 回调（_notifyClosed）        │ invoke
├─ Rust 壳（src-tauri）──────────────────────────────────────────────┘
│    main.rs：起静态服务器 → 建主窗口 → on_navigation 外链分流 → 单实例/退出策略
│    static_server.rs：tiny_http 回环服务器（30031 主站 / 30032 隔离域，IPv4+IPv6）
│    commands.rs：runtime_* 命令（开/导航/聚焦/关窗口、外链、probe、log）
└─ 站点静态文件：dev = 仓库根（实时）；release = bundle resources（_up_ 嵌套）；MAZMOT_WEB_ROOT 可覆盖
```

核心设计决策：**不用 Tauri asset 协议**（`tauri://` 自定义协议源下 Service Worker 无法注册，而 NoneOS Core 依赖 SW），改为壳内置回环 HTTP 服务器 + 真实 `http://localhost` 源，SW / IndexedDB / BroadcastChannel 等平台能力与浏览器完全一致。

## 启动流程（main.rs setup）

1. `resolve_web_root`：`MAZMOT_WEB_ROOT` 环境变量 → debug 构建用 `CARGO_MANIFEST_DIR/../..`（仓库根，实时）→ release 用 `resource_dir`，逐层探测 `_up_`（0-3 层，`../../` 前缀的资源落在 `_up_/_up_/`）。
2. `static_server::spawn` 按 `MAIN_PORTS`（30031 → 30033/30034/30035/30036）依次尝试绑定主站端口；IPv4 必须成功（先绑 IPv4 取实际端口，再以同端口补绑 IPv6，保证双栈同 origin）。30032 固定给隔离域，失败只降级 conjure 预览。
3. `app.manage(HostsInfo { main_port, bridge_port })` 供 `runtime_probe` 读取。
4. 建主窗口 `main`：`http://localhost:<main_port>/`，1200×800 / 最小 860×600，注入 `SHIM_JS`，挂 `on_navigation`。
5. 单实例：二次启动聚焦已有主窗口（`tauri-plugin-single-instance`）。
6. 运行期：主窗口 `CloseRequested` → `app.exit(0)`（关主窗 = 退出整个 runtime，含全部应用窗口）。

## 静态服务器行为规格（static_server.rs）

| 行为 | 规格 |
| ---- | ---- |
| 监听 | 每端口 IPv4+IPv6 双栈各一个 `tiny_http::Server`，每监听 2 个工作线程 |
| 方法 | GET / HEAD，其余 405 |
| Host 校验 | 仅放行 `localhost` / `127.0.0.1` / `[::1]`（带不带端口均可），其余 403（防 DNS rebinding） |
| 路径安全 | percent 解码后拒绝 `..` 段；canonicalize 后必须仍在站点根内 |
| 目录 | 有 `index.html` → 目录 URL 缺尾斜杠时 308 补全（页面相对路径依赖目录形态）；无 index → 404 |
| 404 | 返回 **404 状态 + 顶层 `404.html` 内容**（对齐 CF Pages，禁止 SPA 回退 200 掩盖缺失） |
| 缓存 | `Cache-Control: no-cache` + ETag（mtime-len）；`If-None-Match` 命中回 304 |
| Range | 单区间 `bytes=a-b`（含 `bytes=-N`），206 + `Content-Range`；多区间不支持退回 200 |
| 标记头 | 全部响应带 `X-Mazmot-Runtime: <version>` |

## window.open shim 契约（shim.js）

注入每个 WebView（document-start）。**契约方**：站点 `main/lib/app-status.js` 依赖返回窗口的 `closed`（实时）/ `focus()` / `close()` 三能力追踪应用存活。

| 调用形态 | 行为 |
| ---- | ---- |
| `open(同源URL, name)` | 无同名窗口 → 开原生 WebviewWindow；同名存活 → 聚焦（URL 不同则先导航） |
| `open(url, name, features)` | 解析 `width/height/left/top/resizable` 设定原生窗口几何 |
| `open("", name)` | 只取引用并聚焦，**不触发导航**（对齐浏览器语义，conjure 依赖） |
| `open(外链, ...)` | 系统默认浏览器；返回 `closed` 恒真的假窗口（调用方以此区分「被拦截」报错路径） |
| `_self/_parent/_top` | 当前窗口导航；外链转系统浏览器 |
| 返回的假窗口 | `closed`（用户手关时由 Rust 侧 `eval("_notifyClosed(name)")` 置真）、`focus()`、`close()`（含窗口未建完的 pendingClose 兜底） |

同源判定：host ∈ {localhost, 127.0.0.1, [::1]} 且端口 ∈ 30031-30036。`target="_blank"` 锚点点击捕获走同一分流；外部 http(s) 由 Rust `on_navigation` 兜底分流。窗口标题跟随 `document.title`（500ms 轮询）。启动时 `runtime_probe` 探测结果回传 `runtime_log` 写 stderr——**这是远端源 IPC 是否可用的唯一外部观测点**。

## 自绘顶栏（macOS Overlay 标题栏）

所有窗口（主窗口 + `runtime_open_window` 创建的应用窗口）以 `TitleBarStyle::Overlay` + `hidden_title` 创建：系统标题栏灰条消失，页面内容顶到窗口边缘，macOS 红绿灯浮在左上。VS Code 式顶栏由 shim 注入承担（仅 macOS；`runtime_probe` 返回 `titlebar: "overlay"`，其余平台保持原生标题栏不注入）：

- **顶栏**：40px 固定条，挂 `<html>` 下（ofa 应用可能重写 body，避免被清掉）；`data-tauri-drag-region` 提供拖拽 + 双击最大化（capabilities 显式放行 `core:window:allow-start-dragging` / `core:window:allow-internal-toggle-maximize`）；居中标题跟随 `document.title`；底色自适应页面表面色（采样 body/html computed backgroundColor，兜底 M3 暗色 `#141218`），文字与发丝线按亮度取黑白。
- **内容下移**：`:root` 注入 `--mazmot-tb: 40px` + `body { padding-top: var(--mazmot-tb); box-sizing: border-box }`。站点全站无 `100vh` 布局（统一 `height:100%` 链 + overflow:hidden），该方式不破坏任何页面；固定全屏层（引导/loading，`inset:0`）不随 padding 移动，顶栏底色与其表面色一致故视觉无缝。
- **已知取舍**：站点内 `position: fixed; top: 0` 的浮层（如顶部 toast）会被顶栏盖住（顶栏 z-index 最大）；系统全屏时顶栏仍在。

## 命令速查（commands.rs，全部 `runtime_*`）

| 命令 | 参数（camelCase） | 说明 |
| ---- | ---- | ---- |
| `runtime_open_window` | url/name/width/height/x/y/resizable/opener | 开应用窗口，返回 label（`mazmot-<name>-<seq>`）；窗口 Destroyed 时向 opener eval `_notifyClosed` |
| `runtime_navigate_window` | label/url | 已有窗口导航（conjure 同名复用路径） |
| `runtime_focus_window` | label | show + unminimize + focus |
| `runtime_close_window` | label | 关闭窗口 |
| `runtime_set_window_title` | title | 当前窗口标题同步（调用方隐含 window 参数） |
| `runtime_open_external` | url | opener 插件转系统浏览器 |
| `runtime_probe` | — | 返回 `{version, mainPort, bridgePort}`（shim 启动探测用） |
| `runtime_log` | message | WebView → stderr 日志通道 |

## IPC / ACL 模型

- 页面 origin 是**远端源**（非 tauri 本地源），Tauri 2 对远端源的应用命令强制 ACL 校验，`core:default` 只覆盖核心插件命令。
- `build.rs` 的 `AppManifest::commands()` 为每个 `runtime_*` 生成 `allow-<command>` 权限文件（落在 `src-tauri/permissions/autogenerated/`，gitignore，构建期再生成）；`capabilities/main.json` 显式引用。
- **被拒症状**：invoke promise 静默 reject，无 Rust 日志。诊断路径：shim 的 probe 分支两条路都回传 `runtime_log` → 看进程 stderr。
- 新窗口与主窗口同享 `capabilities/main.json` 的 `windows: ["*"]` 与远端源列表。

## 数据持久性与重置

- origin（含端口）跨启动稳定 → SW 缓存、IndexedDB、localStorage 全部持久；主站端口被外部进程占用时回退候选端口，该次启动 origin 变化会「看不到历史数据」（README 已注明）。
- WebView 数据目录（macOS）：`~/Library/WebKit/com.mazmot.runtime/`。**重置运行时 = 删除该目录**（SW 注册、已装应用、用户数据一并清除）。
- NoneOS Core 首装需联网（core.noneos.com），之后离线可用，与网页版一致。

## 图标管线

`scripts/gen_icon.py`（纯 Python SDF，无 PIL 依赖，~15s）→ `assets/icon.png` → `npx tauri icon` 派生 `src-tauri/icons/` 全平台尺寸 → 打包时进 `.app`。几何比例全部取自 `mz/comps/mascot/mascot.html` 的 CSS（换算系数 K=0.95×em）；调优方法：用浏览器渲染真实 `<m-mascot>` 截图做对照基准。

## 打包产物

各平台产物最终统一收进 **`client/dist/`**（一层目录，`npm run collect`，脚本 `scripts/collect-artifacts.sh`；`dist/` 已 gitignore，产物不入库）。Tauri CLI 的原始输出固定在 `src-tauri/target/release/bundle/<类型>/` 下（macos/ dmg/ 等，路径约定不可改），collect 脚本负责归拢。

- **macOS（arm64）**：`npm run build` → `src-tauri/target/release/bundle/macos/Mazmot.app`（站点资源 3.4M 打进 `Contents/Resources/_up_/_up_/`）；DMG 用 hdiutil 兜底（tauri 的 `bundle_dmg.sh` 需要 Finder 自动化权限，终端里 AppleEvent 超时 -1712）：
  ```bash
  # stage 目录放 Mazmot.app + Applications 软链后：
  hdiutil create -volname "Mazmot" -srcfolder <stage> -ov -format UDZO dmg/Mazmot_1.0.0_aarch64.dmg
  ```
- **Windows（x86_64 / aarch64）便携 zip**：macOS 上经 cargo-xwin 交叉编译（MSVC ABI，WebView2Loader 静态链接，产物只有单 exe）：
  ```bash
  brew install llvm && cargo install cargo-xwin --locked
  rustup target add x86_64-pc-windows-msvc aarch64-pc-windows-msvc
  export PATH="/opt/homebrew/opt/llvm/bin:$PATH"
  cargo xwin build --release --target x86_64-pc-windows-msvc   # aarch64 同理
  ```
  便携包布局（`bundle/windows-portable/Mazmot-<ver>-windows-<arch>.zip`）：`Mazmot/Mazmot.exe` + 站点静态文件平铺在 exe 旁（Windows 的 resource_dir = exe 目录，resolver depth-0 命中）。运行需系统已有 WebView2 Runtime（Win10/11 默认自带）。NSIS/MSI 安装包无法在 macOS 上出，需要时走 GitHub Actions windows runner。

## 踩坑索引

- **远端源 IPC 静默拒绝**：新命令忘配 `build.rs` AppManifest 或 capabilities `allow-*` → invoke 无声失败；`InlinedPlugin` 是错误方案（权限键带 `plugin:<name>|` 命名空间，匹配不上裸命令名）。
- **tiny_http**：`Request::respond(self)` 按值消费，辅助函数必须所有权传递（不能 `&mut`）；`HeaderField::equiv` 参数需 `'static`（传字面量）。
- **双栈同端口**：`port=0` 时 IPv4/IPv6 各绑会得到不同端口——先绑 IPv4 取 `local_addr()` 实际端口，再以该端口绑 IPv6。
- **bundle resources 嵌套**：`tauri.conf.json` 里 `../../` 开头的资源落在 `resource_dir/_up_/_up_/`，解析时逐层探测 `_up_`（现实现探测 0-3 层）。
- **CSS 渐变投影**：CSS `145deg` 渐变在圆上的投影公式是 `t = (0.574dx + 0.819dy + R) / 2R`（第一版图标把环顶画暗就是这里算错）。

## 已知限制

- 主站端口被占用回退后，该次启动 origin 变化（历史数据不可见）；30032 被占用仅 conjure 隔离预览降级。
- 多窗口行为（打开/关闭/命名复用）在 macOS 上机制已验证，真人 UI 走查由开发者执行；Windows（WebView2）/ Linux（webkitgtk ≥ 2.40）未实测。
- `handle_navigation` 对 `blob:` / `data:` / `javascript:` 等页内协议放行；仅 http(s) 非回环源转系统浏览器。
